# 文字描画の差異と改善方針

描画画像の文字は `ab_glyph` のアウトラインを tiny-skia の画像に合成する。原作の Windows GDI と同じフォントでも、ヒンティング、アンチエイリアス、字送りやベースラインの丸めが異なるため、文字の形・位置・幅は画素単位では一致しない。現在のラスタ描画では太字を 1 ピクセルずらした二重描画で近似し、斜体はベースラインを軸に約 12 度（`tan 12° ≈ 0.21`）右へ傾けた画素の合成で近似する。傾きは 1 ピクセル未満の端数を隣の列へ配分するため、段差にならず線の太さも保たれる。下線と取り消し線は傾けず、ベースラインに沿った直線のままである。フォントが見つからなければ文字は描かれず、幅のみ推定される。WMF/EMF はフォント名とスタイルを記録し、表示環境の GDI に描画を委ねるため、ラスタ画像との一致も保証されない。

改善は次の順に検討する。

1. 原作と同じ Windows、DPI、フォント、設定、入力データを使い、日本語・英数字・太字・斜体・小サイズを含む比較画像を収集する。配置と字形を分けて比較し、差異を再現できるテストデータを作る。
2. 太字・斜体の実フォントを選択し、ない場合のみ合成する。文字ごとのフォールバックと、測定・描画で同じフォントを使う仕組みを追加する。
3. GDI 互換が必要な Windows 出力は GDI を使う経路を検討し、他 OS の描画やメタファイルとの違いを明記する。DPI と行送りを揃え、比較画像で回帰確認する。

MS フォントは配布物に含めず、利用者の環境にインストールされたものを実行時に利用する。代替フォントを使用した比較ではフォント名とバージョンも記録する。
