# GUIのエラー通知確認

Windowsでビルドした `avese.exe` を使い、次の手順で読み込みと描画のエラー通知を確認できます。

1. 存在しないファイル名を引数に起動する。メイン画面が表示され、ファイル名と読み込みエラーを含むダイアログが前面に出ることを確認する。
2. 下記の内容をテキストファイルに保存し、通常の「データロード」から開く。描画時に「画像が大きすぎます」というダイアログが表示され、閉じた後もメイン画面を操作できることを確認する。描画サイズの上限を超える設定であり、データは2×2点だけなので大きな画像は作成されない。

```text
[AVESE.EXE]
SEsize=20000
[DATA]
0 0 1
1 0 2
0 1 3
1 1 4
```

データ内の設定を読み込む初期設定を使用する。自動化されたGUIテストはまだ用意されていない。
