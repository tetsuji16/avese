avese は、数値計算の結果などの 3 次元データを、分布図、ベクトル図、等高線図、俯瞰図にするソフトです。テキストファイルをウィンドウに落とすだけで図になります。

無料・オープンソース (MIT) ／ インストール不要 ／ Windows 版を配布、他の OS はソースからビルド

はじめる

インストールは要りません。次の手順で、最初の図が描けます。

  1. ダウンロードした ZIP を展開し、avese.exe を起動します。
  2. データファイルをウィンドウにドラッグ＆ドロップします。ツールバーの左端のボタンからも選べます。手元にデータがなければ、サンプルデータの flow.txt を使ってください。
  3. ツールバーで「ベクトル」や「等高線」を切り替えて、「再描画」を押します。ボタンの名前は、マウスを乗せると出ます。
  4. 図の上でマウスを動かすと、その位置の X、Y、Z の値がステータスバーに出ます。

ツールバーの切り替えは、押しただけでは図に反映されません。最後に「再描画」を押します。

図の種類

どの図も、ツールバーか設定で切り替えられます。下の図はサンプルデータから avese で作ったもので、--set の値はコマンドラインで同じ図を作るときの指定です。

データの書き方

データはテキストファイルです。文字コードは Shift-JIS と UTF-8 のどちらも読めます。1 行が 1 データ点で、値は空白、タブ、コンマで区切ります。

# X  Y  Z  U  V
0  0  1.5  0.2  0.1
1  0  1.8  0.3  0.1
2  0  -    0    0

どの列を X、Y、Z、U、V として読むかは、設定の「入出力」で変えられます。ほかに次の書き方が使えます。

書き方意味
- (Z の位置)その点の周囲を描かず、白く抜きます
空行、記号や英字で始まる行読み飛ばします
Labels x,y,文字列画像の (x, y) 画素に文字を置きます。原点は左上です。数値より前に書きます。「ラベル表示」がオンのときに描かれます
Mesh AutoCreate格子状でない点を三角形に自動分割します。数値より前に書きます
[AVESE.EXE] の節キー=値 の形で設定を埋め込みます。設定「データファイルから設定を読みこむ」がオンのときに有効です
IncludeINI "名前.ini"別の設定ファイルを読み込みます

円筒座標では X、Y が θ、r になり、U、V は θ 方向、r 方向の成分です。「パネル状」を選ぶと Z だけを格子状に並べたファイルとして読み、1 行目が画像の一番上になります。

設定を埋め込む例

[AVESE.EXE]
SEsize=640
CBvector=1
[DATA]
0  0  1.5  0.2  0.1
1  0  1.8  0.3  0.1

設定を変える

ツールバーの「設定」ボタンで設定ダイアログを開きます。変更して OK を押すと、その設定で描き直します。

タブ内容
凡例凡例の表示、Z の範囲指定、グラデーションの種類・色数・反転・折り返し、凡例の大きさ
入出力列の割り当て、読み飛ばす行数、パネルの転置、スプライン補間、データチェック
ラベルラベルのフォント、画面上で追加するラベルの一覧
表示余白、背景色と前景色、各部分のフォント
特殊終了時の設定保存、ビットマップの大きさの上限、画像の形式
俯瞰図高さ、面で表示、視点の角度 (η、φ)
分布図散布図の点の大きさと形
ベクトル間引き、長さ、色、矢印、基準値
等高線本数、範囲、色
座標系、グリッド座標系、線の幅、矢印、タイトル、目盛

データの範囲は、読み込むたびに読み取り専用の欄に表示されます。「指定する」をオンにした項目だけ、入力した値が使われます。設定は「設定保存」で avese.exe と同じフォルダの avese.ini に保存され、次の起動時に読み込まれます。

グラデーション

9 種類から選べます。既定は smooth colors-1 です。コマンドラインでは CBtype=0 から 8 で指定します。

俯瞰図

設定の「俯瞰図」タブで「俯瞰図」をオンにして OK を押します。視点は η と φ の数値か、プレビューの横のスライダーで変えます。プレビューの箱が動くので、向きを確かめながら調整できます。

保存と出力

「セーブ」のファイルの種類で形式を選びます。拡張子を付けずに名前を入れると、選んだ種類の拡張子が付きます。

形式内容
PNGWeb や資料に向いた画像
BMP256 色ビットマップ。無圧縮と RLE 圧縮
EMF、WMFメタファイル
AVI無圧縮の動画。連続処理で作ります
クリップボード「コピー」で送ります。設定の「イメージの取り扱い」でビットマップか EMF を選びます。Windows のみです

連続処理と動画

複数のファイルを選ぶか、まとめてドロップすると「連続処理」ダイアログが開きます。計算のステップごとの結果を、連番の画像や動画にできます。

  1. 「追加」「削除」「ソート」「↑」「↓」で一覧を整えます。ソートは数字を数として比べるので、frame2 は frame10 より前に並びます。
  2. 「BMP作成」は、ファイルごとに ファイル名.bmp を保存します。
  3. 「AVI作成」は、一覧の順に 1 コマずつ並べた無圧縮 AVI を作ります。「フレームレート」でコマ数を、「サイズ指定」で大きさを決めます。

色の範囲がコマごとに変わらないよう、「凡例」タブで Z の最小値と最大値を指定しておくと動画が見やすくなります。ページ先頭の波の動画は −2 から 2 に固定しています。

コマンドライン

ウィンドウを開かずに画像や動画を作れます。計算の後処理に組み込むときに使います。

avese データ.txt
avese --render データ.txt 出力.png [--rle] [--ini 設定.ini] [--set キー=値]...
avese --avi 出力.avi --fps 10 [--frame-size 640x480] [--ini 設定.ini] [--set キー=値]... データ1.txt データ2.txt ...

出力の形式は拡張子で決まります (.png、.bmp、.emf、.wmf)。--rle を付けると .bmp が RLE 圧縮になります。設定は --ini のファイル、--set の順に適用されます。

例

avese --render flow.txt vector.png --set SEsize=520 --set CBvector=1 --set CBskipx=1 --set CBskipy=1 --set EDstepx=4 --set EDstepy=4
avese --avi wave.avi --fps 12 --frame-size 640x480 --set CBenZmin=1 --set EDenZmin=-2 --set CBenZmax=1 --set EDenZmax=2 wave/wave01.txt wave/wave02.txt wave/wave03.txt

よく使うキー

キー意味
SEsize図の大きさ (ピクセル)
CBgraph, CBscatter, CBpanel分布図、散布図、パネル (0 か 1)
CBvector, CBtokoベクトル、等高線 (0 か 1)
CBskipx, CBskipy, EDstepx, EDstepyベクトルの間引きの有無と間隔
SEtoko等高線の本数
CBaxis, CBgrid, CBpoint, CBlegend座標軸、グリッド、データ点、凡例 (0 か 1)
CBland, CBsurface, SElandheight, SEeta, SEphi俯瞰図、面で表示、高さ、視点の角度
CBtype, CBreverse, CBfoldグラデーションの種類 (0 から 8)、反転、折り返し
CBenZmin, EDenZmin, CBenZmax, EDenZmaxZ の範囲の指定

ダウンロード

最新の安定版は v1.0.0 です。Windows (x64) で使えます。ZIP を展開して avese.exe を起動してください。インストールは要りません。

v1.0.0 をダウンロード (ZIP)

変更点と過去の版は GitHub の Releases にあります。

ほかの OS では、Rust を入れてソースからビルドしてください。クリップボードは Windows のみです。

git clone https://github.com/tetsuji16/avese.git
cd avese
cargo build --release
