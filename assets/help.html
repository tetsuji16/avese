avese ヘルプ

avese は、数値計算の結果などの 3 次元データを、色の分布図、ベクトル図、等高線図、俯瞰図として画像にするソフトです。 2001 年の Delphi 製ソフト「ＡＶ似非」(作者: おりいる) を Rust で作り直した、非公式の再実装版です。

使い方

  1. 「ロード」ボタン (メニューの「データロード」) でデータファイルを選ぶと、読み込んで図を描きます。ウィンドウにファイルをドラッグ＆ドロップしても読み込めます。
  2. 「詳細設定」で表示内容を変えて OK を押すと、その設定で描き直します。ツールバーやメニューの表示項目を変えたあとは「再描画」を押します。
  3. 「セーブ」で画像として保存、「コピー」でクリップボードに送ります。

複数のファイルを選ぶか、まとめてドロップすると「連続処理」ダイアログが開きます。

データファイル

テキストファイルです。文字コードは Shift-JIS と UTF-8 のどちらも読めます。1 行が 1 データ点で、値は空白、タブ、コンマで区切ります。

X  Y  Z  U  V
0  0  1.5  0.2  0.1
1  0  1.8  0.3  0.1
  • どの列を X、Y、Z、U、V として読むかは、詳細設定の「入出力」で決めます。円筒座標では X、Y が θ、r になり、U、V は θ 方向、r 方向の成分です。
  • Z の位置に半角の - を書くと、その点の周囲は描かず、白く抜けます。
  • 「パネル状」を選ぶと、Z だけを格子状に並べたファイルとして読みます。1 行目が画像の一番上です。
  • 空行、# などの記号で始まる行、英字で始まる行は読み飛ばします。
  • 数値より前に Labels x,y,文字列 と書くと、画像の (x, y) 画素 (左上が原点) に文字を置きます。「ラベル表示」がオンのときに描かれます。
  • 数値より前に Mesh AutoCreate と書くと、格子状でない点を三角形に自動分割して描きます。
  • 「データファイルから設定を読みこむ」がオンのとき、[AVESE.EXE] の節に キー=値 の形で設定を書けます。IncludeINI "名前.ini" で別の設定ファイルも指定できます。

設定のグループ

グループ内容
凡例凡例の表示、Z の範囲指定、グラデーションの種類・色数・反転・折り返し、凡例の大きさ
入出力列の割り当て、読み飛ばす行数、パネルの転置、スプライン補間、データチェック
ラベルラベルのフォント、画面上で追加するラベルの一覧
表示余白、背景色と前景色、各部分のフォント
特殊終了時の設定保存、ビットマップの大きさの上限、画像の形式 (ビットマップ／メタファイル)
俯瞰図高さ、面で表示、視点の角度 (η、φ)
分布図散布図の点の大きさと形
ベクトル間引き、長さ、色、矢印、基準値
等高線本数、範囲、色
座標軸・グリッド座標系、線の幅、矢印、タイトル、目盛

データの範囲 (X、Y、Z、ベクトル、等高線) は、読み込むたびに設定ダイアログの読み取り専用欄に表示されます。「指定する」をオンにした項目だけ、入力した値が使われます。

図の大きさはツールバーの「サイズ指定」と「代表長さ」で決め、縦横の倍率は別に指定できます。設定は「設定保存」でプログラムと同じフォルダの avese.ini に保存され、起動時に読み込まれます。

ステータスバー

平面図の上でマウスを動かすと、その位置の X、Y、Z の値を表示します。円筒座標では θ と r です。俯瞰図では表示しません。

セーブとクリップボード

「セーブ」のファイルの種類で形式を選びます。

  • ビットマップ (256 色、無圧縮)、RLE 圧縮ビットマップ、PNG
  • エンハンストメタファイル (EMF)、ウィンドウズメタファイル (WMF)

拡張子を付けずに名前を入れると、選んだ種類の拡張子が付きます。「コピー」は、設定の「イメージの取り扱い」がビットマップなら 256 色ビットマップを、メタファイルなら EMF をクリップボードに入れます。

連続処理

「追加」「削除」「ソート」「↑」「↓」でファイルの一覧を整えます。ソートはファイル名の順で、数字は数として比べます (frame2 は frame10 より前)。

  • 「BMP作成」: 一覧のファイルを 1 つずつ描き、選んだフォルダに ファイル名.bmp として保存します。
  • 「AVI作成」: 一覧の順に 1 コマずつ並べた無圧縮 AVI を作ります。「フレームレート」でコマ数を、「サイズ指定」で画像の大きさを決めます。指定しないときは先頭のファイルの大きさになります。

各ファイルは、現在の設定のコピーで読み込みます。ファイルに埋め込まれた設定が次のファイルに影響することはありません。

コマンドラインから使う

ウィンドウを開かずに画像を作れます。設定は --ini で設定ファイルを、--set キー=値 で個別の値を指定します。

avese --render データ.txt 出力.png [--rle] [--ini 設定.ini] [--set CBmode=1]...
avese --avi 出力.avi --fps 10 [--frame-size 640x480] [--ini 設定.ini] [--set キー=値]... データ1.txt データ2.txt ...

出力の形式は拡張子で決まります (.png、.bmp、.emf、.wmf)。--rle を付けると .bmp が RLE 圧縮になります。

ひとこと

大きすぎる画像を描こうとすると、「特殊」で決めた上限を超える旨の確認が出ます。ファイルが読めないとき、データが不正なときは、理由をダイアログで表示します。
