avese Help

avese turns three-dimensional numeric data into distribution, vector, contour, and bird's-eye plots. It is an unofficial Rust reimplementation inspired by the 2001 Delphi application AVese.

Getting started

  1. Choose File > Load Data, or drag data files onto the window. The data is loaded and plotted.
  2. Open Settings to change the plot. Press OK to apply the settings. After changing display toggles on the toolbar or menu, choose Redraw.
  3. Use Save Image to export a picture, or Copy to Clipboard to copy it.

Selecting or dropping several files opens Batch Processing.

Data files

Data files are plain text in Shift-JIS or UTF-8. Each row contains one point; separate values with spaces, tabs, or commas.

X  Y  Z  U  V
0  0  1.5  0.2  0.1
1  0  1.8  0.3  0.1
  • Choose the columns for X, Y, Z, U, and V in Settings > I/O. In cylindrical coordinates, X and Y represent θ and r, while U and V are their vector components.
  • Use a hyphen in the Z column for a missing point. Its surrounding cells are left blank.
  • Select Panel Plot for data arranged as rows of Z values. The first row appears at the top.
  • Blank lines and lines beginning with comment characters or letters are skipped.
  • Before the numeric rows, Labels x,y,text adds a label at image pixel (x,y). Enable Labels to display it.
  • Mesh AutoCreate triangulates scattered points automatically.
  • Enable loading settings from data to read embedded [AVESE.EXE] key/value settings and IncludeINI "file.ini".

Settings

Settings are grouped into Legend, I/O, Bird's-eye View, Distribution, Vectors, Contours, Coordinates, Grid, Labels, Display, Fonts, and Advanced. Read-only fields show the data ranges; enable a range checkbox to use a custom value.

Plot size is controlled by Size and Reference Length on the toolbar. Horizontal and vertical scale can be set separately. Settings are saved to avese.ini beside the application and loaded at startup.

Status bar

Move the pointer over a 2D plot to see its X, Y, and Z values. Cylindrical plots show θ and r. The status bar does not probe bird's-eye views.

Export and clipboard

Choose an output type in Save Image: 256-color bitmap, RLE bitmap, PNG, EMF, or WMF. Copy to Clipboard uses the bitmap or EMF format selected under Image Options.

Batch processing

Use Add, Remove, Sort, and the up/down buttons to arrange files. Sort compares numbers naturally (frame2 comes before frame10).

  • Create BMP renders each file and saves it as filename.bmp in the selected folder.
  • Create AVI writes an uncompressed AVI in list order. Frame Rate sets frames per second. Set Size to resize frames; otherwise the first file's image size is used.

Each file starts with a copy of the current settings, so embedded settings in one file do not carry over to the next.

Command line

Render without opening a window. Use --ini for a settings file and --set key=value for individual options.

avese --render data.txt output.png [--rle] [--ini settings.ini] [--set CBmode=1]
avese --avi output.avi --fps 10 [--frame-size 640x480] data1.txt data2.txt

The output extension selects PNG, BMP, EMF, or WMF. Use --rle for RLE-compressed BMP.
