# avese（非公式 Rust 再実装）

Delphi 製のフリーウェア「AV似非」（作者: おりいる）の GUI を、Rust と egui（eframe 0.37）で再実装したものです。
**非公式**であり、原作者・原作とは関係ありません。

## 現状

GUI のみです。描画エンジンはありません。

- 6 つのフォーム（メイン、設定 13 タブ、連続処理、ラベルの追加、バージョン情報、三角メッシュ自動生成）を、原作の DFM から取り出したレイアウト（ピクセル座標）で描画します。
- メニュー、5 本のツールバー（バンドのドラッグと行スナップ）、ステータスバー、ヒント、各種連動（表示項目の排他規則、設定ダイアログ内の連動）。
- INI の読み書き（キーの順序、Shift-JIS、`[avese.exe]`、exe 横の `avese.ini`。`CBautosave=0` なら終了時に保存しません）。
- ファイルダイアログ、ドラッグ＆ドロップ、コマンドライン引数（複数ファイルは連続処理ダイアログに一覧表示）。
- 画像のセーブ、クリップボード、AVI、BMP 作成はダイアログの後に「未実装」と表示します。
- ヘルプは exe 横の `avese.htm` を開きます。無ければメッセージを出します。
- キャンバスは空白です。ファイルを 1 つ読み込むとタイトルが更新され、再描画が有効になるだけです。

## ビルド

```
cargo build --release
cargo test
```

## アセットの取り出し（任意）

アイコンなどは原作の exe に含まれるため、リポジトリには含めません。原作の exe を手元に置き、次を実行すると `assets/local/`（git 管理外）に取り出します。

```
python -I tools/extract_assets.py
python -I tools/export_forms.py
```

`assets/local/` が無い場合は、コードで描いた代替アイコンで動きます。`assets/forms/` のフォーム JSON は、ラベルや座標などレイアウトだけを含み、画像などのバイナリは含みません。

## 既知の差異

- フォントの描画は GDI と同一ではありません（字形・ヒンティングが異なります）。
- `pixels_per_point` は OS の値のままで、倍率の高い画面では原作と物理サイズが異なります。
- 複数ファイルを指定した場合、原作はメインウィンドウを隠しますが、eframe のルートウィンドウを隠すと更新が止まるため、表示したままです。
- 設定ダイアログの `TBeta`/`TBphi` と `SEeta`/`SEphi` は同じ値で連動させています（原作の変換式は未確認）。角度プレビュー（PBangle）は近似の枠線です。
- 凡例タブのグラデーションプレビューは近似です。
- ダイアログは OS ウィンドウで、Windows ではオーナー設定とメイン無効化でモーダルにしています。他 OS ではメインの入力を無視するだけです。
- 三角メッシュ自動生成ダイアログには、GUI から開く経路がありません（コマンドライン引数 `--mesh` 等も未実装）。
